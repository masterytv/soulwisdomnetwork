# Site fonts

Loaded by `app/layout.tsx` with `next/font/local`, so builds never download them. Each is the variable font's Latin
file as Google Fonts serves it (weights 100 to 900), saved on 8 October 2026:

- `Outfit-latin.woff2`: Outfit, copyright 2021 The Outfit Project Authors (https://github.com/Outfitio/Outfit-Fonts)
- `Geist-latin.woff2` and `GeistMono-latin.woff2`: Geist and Geist Mono, copyright 2024 The Geist Project Authors
  (https://github.com/vercel/geist-font)

All three are under the SIL Open Font License 1.1 (`OFL.txt`), which allows bundling them with the site.
